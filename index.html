⚡ 2. TWITCH VS KICK

• Twitch: Requiere RTMP estándar, keyframes obligatorios cada 2s (GOP 60 a 30fps) y OAuth Helix API para títulos.
• Kick: Requiere RTMPS obligatorio (puerto 443 con TLS) y tolera mayor variación de bitrate.
